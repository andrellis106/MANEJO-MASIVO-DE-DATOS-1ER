# Análisis de Rendimiento de Estudiantes

Proyecto individual de análisis y preprocesamiento de datos utilizando el dataset "Students Performance in Exams" de Kaggle.

## Requisitos e Instalación
1. Crear entorno virtual: `python -m venv venv`
2. Activar entorno virtual: `venv\Scripts\activate`
3. Instalar dependencias: `pip install -r requirements.txt`
